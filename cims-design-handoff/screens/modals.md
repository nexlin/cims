# 모달

## M3 · 시스템 추가 (폭 660)

트리 하단 `+ 시스템 추가` 에서 열립니다. `Dialog` + `system-create-form`.

```
시스템 추가                                                    ✕
─────────────────────────────────────────────────────────────
이름 *            [ 예: Control-Server                      ]
                  트리와 대시보드에 표시되는 이름

유형 *            [ AS — Active/Standby (master + backup 2서버 자동) ▾ ]

auth_pass *       [ ••••••••                                 ]
                  VRRP 인증 비밀번호 — 멤버 간 동일

멤버 1 (master)   [ 신규 서버 생성 — <이름>-01 ▾ ]
멤버 2 (backup)   [ 신규 서버 생성 — <이름>-02 ▾ ]
─────────────────────────────────────────────────────────────
☑ 공유 스토리지 마운트를 함께 적용 — 서버 등록 직후 자동으로 붙입니다 (fstab 영속)

원본 *            [ 121.161.164.105:/home/cbm/NAS/cims       ]
붙일 위치 *       [ /mnt/cims                                ]
파일시스템 *      [ nfs ▾ ]

등록 직후 …:/home/cbm/NAS/cims → /mnt/cims (nfs, defaults,_netdev,nofail) 로 마운트하고
콘솔 [마운트 관리]에 표시됩니다. 마운트가 실패해도 서버 등록은 유지됩니다.

  선택: AS (서버 2 자동) · 멤버 이름: <이름>-01 (master), <이름>-02 (backup)
─────────────────────────────────────────────────────────────
                                              [취소]  [생성]
```

**조건부 폼입니다.** 유형에 따라 필드가 바뀝니다.
- `AS` — auth_pass 필수, 멤버 2 자동
- `AA` — auth_pass 없음, 멤버 n대
- `SA` — auth_pass 없음, 멤버 1대

하단 요약 문장은 선택에 따라 실시간으로 바뀝니다.

## 미작성 — 확인 대화상자
삭제 · 폐기 · 재시작 · 롤백 · 재설치 · 일괄 제어 · 절체.
운영 서버라 실제로 눌러보지 못해 **웹에 확인 대화상자가 있는지 미확인**입니다.
있어야 한다고 보고 `Dialog Tone=Danger` 로 그릴 준비는 되어 있습니다 — 문구는 확인 후 작성.
