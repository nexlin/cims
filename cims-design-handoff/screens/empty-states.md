# 빈 상태 5종

화면마다 다른 문구를 만들지 말고 이것만 쓰세요. 전부 웹 실측 문구입니다.

## ES-1 · VIP Bindings (0)
**AS · AA 공통** — 그룹 › 시스템/서버 구성 › VIP Bindings. 멤버에 service IP 가 없으면 AS 에서도 납니다.
```
VIP 없음
all_active 그룹은 비워둬도 됩니다 (keepalived 안 깔림). active_standby 는 1개 이상 권장.
```
+ Warning Alert:
```
멤버 서버에 용도(service IP) 가 없습니다
멤버의 [네트워크] 탭에서 IP 별 용도를 입력해야 VIP 를 자동 매핑할 수 있습니다.
```
> 경고의 조치 지점이 **다른 화면**입니다. 해당 멤버로 가는 바로가기 링크를 넣어주세요.

## ES-2 · 그룹 패키지 설정 — 모듈 없음
탭 본문 전체가 이 한 줄로 대체됩니다. 모듈 칩·세그먼트·저장바 모두 표시하지 않습니다.
```
그룹 멤버에 배포된 모듈 없음
[패키지 설치] 탭에서 모듈을 먼저 배포하세요.
```

## ES-3 · 패키지 제어 — 모듈 0건 셀
행은 남기고 `모듈 · 버전` 셀만 이 문구로. 제어 버튼은 표시하지 않습니다.
```
배포된 모듈 없음
```

## ES-4 · 멤버 미접속 (approved)
등록·승인은 됐지만 heartbeat 가 없는 상태. 상태·접속·IP·버전이 모두 `—`. StatusDot 은 **Info**.

## ES-5 · 마운트 미적용
일부 멤버에만 적용된 상태. 헤더에 `미적용 n건`(warningSoft) 배지, 멤버별 상태 셀에 `✕ <서버명>`, 행 액션에 `없는 멤버에 적용`.
**행 전체를 노란 배경으로 칠하지 마세요** — 배지와 ✕ 로 충분합니다.
