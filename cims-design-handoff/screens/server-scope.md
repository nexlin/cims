# 서버 스코프 (S1~S4)

트리에서 **그룹 하위의 서버**를 선택했을 때. ContextBar 는 `ServerContextBar`.

```
● Control-01 ✎ (online)  #1 · v0.2.85 ······  [메트릭] [점검] [더보기 ▾]
```
`더보기` 안: 재시작 · 업그레이드 · (롤백) · 폐기 · 삭제
- **롤백은 이전 버전이 보존된 경우에만** 나타납니다
- **삭제는 AS 그룹 멤버면 비활성** + 사유 `그룹 삭제로만 가능`

---

## S1 · 시스템/서버 구성

### 정보 (2열 그리드, 12필드)
이름 · 호스트 · IP · OS · CPU 코어 · 메모리 · 디스크 · Agent 버전 · 등록 시각 · 승인 시각 · 마지막 heartbeat · 메모

### 네트워크 (Level 1) — 하위 5섹션 (Level 2)

**IP / Routing (3)** · 힌트 `cims-managed 만 변경 가능 — 외부 IP / mgmt NIC 은 보호`
| 인터페이스 | IP / mask | 용도(slot) | 소유 | 액션 |
- mgmt NIC 은 자물쇠 + `mgmt` 태그, 액션 없음
- 용도 슬롯은 인라인 입력. 비어 있으면 placeholder `(용도)`
  → **빈 입력인지 미설정인지 구분되게** 하세요. 현재 웹은 구분이 안 됩니다
- Info Alert: `인프라 단계 — NIC 이름이 곧 용도 라벨로 사용됩니다`

**라우팅 (3)** · 힌트 `subnet 자동(kernel) 외 모두 변경 가능 — default gateway 포함`
| dest CIDR | gateway | dev | 소유 | 액션 |
- 소유: `★ default` / `🔒 kernel`(자물쇠 아이콘) — kernel 행은 액션 `—`

**마운트 (1)** · 힌트 `콘솔에서 추가하면 /etc/fstab 에 기록되어 재부팅에도 유지 · 네트워크 FS 는 _netdev,nofail 자동`
| 마운트 위치(target) | 소스(source) | 유형 | 옵션 | 상태 | 액션 |
- **소스 컬럼 최소폭을 충분히** — 현재 웹은 NFS 경로가 6줄로 쪼개집니다

**OAM 접속 주소 (agent → OAM)**
```
이 서버의 agent 가 heartbeat·job 결과를 보내는 주소입니다. 관리평면이 이중화면 VIP 여야 합니다 —
노드 IP 로 두면 절체 후 이 agent 가 OAM 과 단절되고, 콘솔에서는 이 서버가 offline 으로 보입니다.

현재 보고 주소  https://121.161.164.140:4419        [이 서버 적용] [전체 적용]

적용하면 agent 가 재기동되어 새 주소로 붙습니다(수 초).
새로 설치되는 agent 의 초기 주소는 oam 설정 > Agent→OAM URL 이 정합니다.
```

**네트워크 튜닝 (RPS / sysctl)**
- RPS 표: 인터페이스 · rps_cpus 마스크(입력 + `전체코어` 버튼) · 현재 저장값
- sysctl 표: 키 · 값 · 설명 — netdev_max_backlog · netdev_budget · rmem_max · wmem_max
- 하단 `네트워크 튜닝 적용`

## S2 · 패키지 설치
`모듈 (n)` — 부제 `설치·버전 관점 — 시작·정지는 «패키지 제어» 탭`
| 모듈 | 버전 | 빌드 · git | 상태 | 작업 |
- 작업: 재설치 · 업그레이드 · 롤백 · 삭제 (전부 outline, 삭제만 아이콘)
- **롤백은 이전 버전이 보존된 모듈에서만 활성**
- 하단 `+ 모듈 추가`

## S3 · 패키지 설정
상단 모듈 칩(모듈명 · 버전 · 설정 개수) → 선택 모듈의 설정.
`서버 개별 설정 (4)` + 범례 `🔁 재기동 필요 · ⚡ 즉시 적용`

Info Alert (그룹 멤버일 때만):
```
이 화면은 이 서버 고유 설정(bind IP · 노드 식별자 등)만 다룹니다
그룹 공통 설정 9개 필드와 공통 컬렉션은 좌측 트리에서 그룹 <이름> 선택 → [패키지 설정] 에서
편집합니다 (동기화 스위치 포함).
```
+ 우측 `그룹 공통 설정 편집 →` 링크. **SA 단일 서버에서는 이 Alert 와 링크를 숨깁니다.**

- **OAM 서버 / 포트**: bind IP* · OAM 역할*(base/all)
- **Infrastructure (내부 전용)** — 기본 접힘, 2필드: `시크릿 › 콘솔/게이트웨이 JWT 시크릿`, `런타임 / 패키지 경로 › 인증서 추가 주소(SAN)`
- 저장바: `[재기동] 저장 후 oam 을 재기동하면 새 bind 설정이 적용됩니다  … [되돌리기] [저장 (0 변경)]`

## S4 · 패키지 제어
Info Alert `여기서 제어하는 대상은 <서버> 의 모듈입니다 / 서버 자체를 재시작하려면 위 ContextBar 의 «더보기 › 재시작» 을 사용하세요 — 대상이 다릅니다.`

`모듈 제어 (n)` — 부제 `런타임 관점 — 버전·재설치는 «패키지 설치» 탭`
| 모듈 | 버전 | 모듈 상태 | 제어 |
- 제어: 시작 · 재시작 · 정지
- **현재 상태에서 불가능한 동작은 비활성** — running 이면 `시작`, stopped 이면 `재시작·정지`
- **일괄 버튼 없음** (그룹 화면 전용)
