# 화면 목록

> 실물은 **`FIGMA-LINKS.md`** 에서 화면별로 바로 열 수 있습니다 (무료 계정 · view-only).

경로: `/deploy/servers` — 좌측 트리에서 **무엇을 선택했는가**에 따라 스코프가 바뀌고, 스코프마다 같은 4탭이 다른 내용을 보여줍니다.

| 스코프 | 트리에서 선택 | 화면 |
|---|---|---|
| **서버** (그룹 멤버) | 그룹 하위의 서버 | S1 · S2 · S3 · S4 |
| **AS 그룹** (active_standby) | AS 배지가 붙은 시스템 | G1 · G2 · G3-1~6 · G4 |
| **AA 그룹** (all_active) | AA 배지가 붙은 시스템 | A1 · A2 · A3 · A4 |
| **SA** (단일 서버) | SA 배지가 붙은 시스템 | SA1 · SA3 (SA2·SA4 는 S2·S4 와 동일) |
| 모달 | — | M1 메트릭 · M2 실시간 점검 · **M3 시스템 추가** |
| 제안 | — | P1 사이드바 컨트롤 재배치 · G1b 상세편집 통합안 |

| 화면 | 탭 | 내용 |
|---|---|---|
| **S1** | 시스템/서버 구성 | 정보 12필드 · 네트워크(IP/Routing · 라우팅 · 마운트 · **OAM 접속 주소** · 네트워크 튜닝) |
| **S2** | 패키지 설치 | 모듈 표 — 재설치/업그레이드/롤백/삭제 + 모듈 추가 |
| **S3** | 패키지 설정 | 서버 개별 설정 **(4)** — bind IP · OAM 역할 + Infrastructure(2) |
| **S4** | 패키지 제어 | 모듈 제어 — 시작/재시작/정지 (일괄 버튼 없음) |
| **G1** | 시스템/서버 구성 | 그룹 설정 · 절체 조건 9 · 멤버 · VIP · 마운트(그룹 공통) |
| **G2** | 패키지 설치 | 멤버별 배포 현황 — **조회 전용** |
| **G3-1/3/5** | 패키지 설정 · 공통 설정 | 모듈별 **공통 설정 (9)** + 이관 |
| **G3-2/4/6** | 패키지 설정 · 멤버 비교 | 5섹션 13행 + 요약 칩 |
| **G4** | 패키지 제어 | 그룹 일괄 제어 + 멤버별 프로세스 제어 |
| **A1~A4** | AA 그룹 4탭 | AS 와의 차이는 `aa-group.md` |
| **SA1** | 시스템/서버 구성 | S1 과 동일. 트리만 단일 시스템 |
| **SA3** | 패키지 설정 | **서버 개별 설정 (13)** — 그룹이 없어 공통 9필드가 여기로 내려옴 |
| **M3** | 모달 | 시스템 추가 — 이름·유형·auth_pass·멤버2 + 공유 스토리지 마운트 |

빈 상태는 `empty-states.md`, 공통 셸은 `shell.md` 를 보세요.
