# AA 그룹 스코프 (A1~A4)

`all_active` — 두 멤버가 동시에 서비스. **절체 개념이 없습니다.**

## AS 와 다른 점 (전부 실측 확인)

| 항목 | AS | **AA** |
|---|---|---|
| 그룹 설정 | 그룹 이름 · auth_pass · note | **note 만** (VRRP 인증 없음) |
| 절체 조건 | 9필드 섹션 | **섹션 자체가 없음** |
| 멤버 표 | 이름·역할·MASTER·상태·접속·IP·Agent + 실측 | **이름·접속·IP·Agent** 4컬럼, MASTER 지정 없음, 실측 없음 |
| VIP | 보통 1건 이상 | 0건이 정상 — ES-1 |
| 공유 store | 있음 | 없음 |
| 패키지 설정 | `공통 설정 \| 멤버 비교` 2세그먼트 | **`멤버 비교` 만** |
| 패키지 제어 | 일괄 3 + 수동 절체 | **일괄 3만** |
| 멤버 행 | `점검` `복귀` 있음 | **없음** |
| 트리 | 서버 2대 고정 | **`+` / `×` 로 멤버 증감** |

A1 상단 Info Alert:
```
이 화면의 변경은 그룹 멤버 전체(Media-01, Media-02)에 적용됩니다
all_active 그룹은 절체 개념이 없어 절체 조건·공유 store 섹션이 없습니다.
```

A3 본문 (모듈에 config_template 이 없을 때):
```
이 패키지에는 config_template 이 없습니다 — 설정 항목 없음
```

A4 하단 주석:
```
all_active 그룹은 절체가 없어 두 멤버가 동시에 서비스합니다 — 한 대를 정지하면 그만큼 용량이 줄어듭니다.
```
