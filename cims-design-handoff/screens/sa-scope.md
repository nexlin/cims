# SA 스코프 (단일 서버) — SA1 · SA3

트리 배지 `SA`. 그룹이 없는 단독 서버입니다.

## 핵심 규칙 — 필드가 스코프를 따라 이동합니다

| | 서버 화면의 `패키지 설정` | 나머지 |
|---|---|---|
| **그룹 멤버** (AS/AA) | **(4)** — bind IP · OAM 역할 + Infrastructure(2) | 공통 9필드는 **그룹 화면** |
| **SA 단독** | **(13)** — 위 + 서비스 로그 3 + 관리 store 3 + 관리망 2 | 그룹이 없으므로 전부 여기 |

## SA1 · 시스템/서버 구성
S1 과 동일. 다른 것:
- 트리가 `SA <서버명>` 한 줄, 헤더 `시스템 1 · 서버 1`
- **`삭제` 가 활성** (그룹 멤버가 아니므로)

## SA3 · 패키지 설정
- 제목 `서버 개별 설정 (13)`
- **`그룹 공통 설정 편집` 링크와 안내 Alert 를 표시하지 않습니다** (그룹이 없음)
- 섹션: OAM 서버/포트(OAM bind 포트 · bind IP · OAM 역할) · 서비스 로그(3) · 관리 store(3) · 관리망 · agent 접속(2) · Infrastructure(2)
- **`이관` 버튼은 비활성** + 사유:
  ```
  이관은 HA 그룹 멤버에서만 실행할 수 있습니다 — 이 서버는 단일 노드라 비활성입니다.
  부트스트랩 재설치 또는 그룹 편성 후 실행하세요.
  ```

SA2 · SA4 는 S2 · S4 와 동일합니다 (트리만 단일 시스템).
