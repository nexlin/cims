# 왜 이렇게 바꿨는지

리뷰에서 "원래대로 하죠" 로 되돌아가지 않도록, 시안이 현재 웹과 **다르게** 그려진 곳과 그 이유만 모았습니다.

## 1. 헤더 재정리
현재 웹 헤더는 라벨 없는 아이콘 5개(편집 · `<>` · 테마 · 자물쇠 · 로그아웃)입니다. 성격에 따라 세 곳으로 나눴습니다.
- 다크 모드 · 개발자 모드 → **[설정] 드롭다운의 토글 스위치**. 라벨을 「테마」가 아니라 「다크 모드」로 둔 이유는 스위치의 꺼짐/켜짐이 라이트/다크에 대응해야 하기 때문입니다.
- 비밀번호 변경 · 로그아웃 → **[관리자] 계정 메뉴**. 로그아웃을 톱니바퀴에 넣으면 오히려 못 찾습니다.
- **알람 배지 신설** — 기존에는 장애 여부를 알려면 장애 메뉴로 이동해야 했습니다.
- **접속 환경 칩 + 호스트 + 갱신 시각 신설** — 여러 인스턴스를 운영하는데 어디에 접속했는지 표시가 없었습니다.

## 2. 위젯 편집 제거 (재검토 필요)
웹 헤더의 ✎ 버튼(접근성 이름 `이 페이지를 위젯으로 편집`)은 **실재하는 기능**입니다. 누르면 페이지 전체가 편집 캔버스로 바뀌고 70종 이상의 위젯 카탈로그가 열립니다.
시안에서는 채택하지 않았습니다. **되살릴지 여부는 아직 미결** — 되살린다면 전역 헤더가 아니라 breadcrumb 줄 오른쪽의 페이지 액션 자리입니다.

## 3. 그룹 ContextBar 를 4탭 전부에 유지 (동작 변경)
웹은 그룹 식별 줄이 `시스템/서버 구성` 탭에만 있고 나머지 3탭에서 사라집니다. 어느 그룹인지 · vrid · 삭제/설정 비교 진입점이 통째로 없어집니다. 시안은 4탭 전부에 유지합니다.

## 4. 서버 액션을 [더보기] 로 묶음
웹은 `메트릭 · 점검 · 재시작 · 업그레이드 · 롤백 · 폐기 · 삭제` 7개가 한 줄에 나열되고, 그중 `삭제` 가 빨간 solid 로 상시 노출됩니다. 시안은 `메트릭 · 점검 · [더보기 ▾]` 로 줄이고 파괴적 액션을 드롭다운 안으로 넣었습니다.

## 5. 표에서 build/git 을 분리
웹은 모듈 표의 설명 칸에 `| build: … | git: …` 원문이 들어가 행 높이가 제각각입니다. 시안은 `빌드 · git` 을 별도 컬럼으로 뺐고, 긴 설명은 한 줄 요약 + 툴팁입니다.

## 6. 일괄 제어에서 성격 분리
프로세스 제어(시작·재시작·중지)와 HA 절체는 위험도가 다릅니다. 구분선으로 갈랐습니다.

## 7. 제안이라 표시된 것 (웹에 없음)
- 저장바의 **되돌리기** — 저장 전 폼 초기화. 웹에는 없습니다
- 탭의 **카운트 배지** (`패키지 설치 3`) — 웹에는 없습니다
- G4 상단의 **동시 정지 경고** — VIP 가 있는 그룹에서만 유효합니다

## 8. 웹 쪽 결함으로 판정해 시안에 옮기지 않은 것
- 표 헤더가 글자 단위로 세로 줄바꿈되는 것 (`액`/`션`, NFS 경로 6줄 분해)
- 이모지·텍스트 글리프 아이콘
- 모듈 이름 대소문자 혼용 (`oam` / `OAM-SVC` / `CSC`, 같은 그룹의 두 멤버가 서로 다름)
- 드리프트 **0건**인데 노란 ⚠ 로 표시
- 포커스 링 없음
- 마운트 미적용 행 전체를 노란 배경으로 칠하는 것
