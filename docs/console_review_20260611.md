## 2. 확인·결정이 필요한 항목 (사용자)

1. **고객 문서의 SIP 포트 기술** — 문서 페이지(시스템 아키텍처/UE 연동 규격)가 `UDP 5060` 기준으로
   기술돼 있습니다. 운영 표준은 15060(local_nodes 컬렉션)으로 전환된 상태라,
   ⓐ 문서를 15060 기준으로 갱신 ⓑ "기본 5060, local_nodes 로 운영 변경(현 표준 15060)" 주석 병기 —
   어느 쪽으로 갈지 결정해 주세요. (고객 배포 문서라 임의 수정 보류)

2. **서비스 정의(서비스 팩)의 csp 포트 5060** — 구성>서비스 정의의 모듈 표와 agent health_check
   기본 프로브가 5060 입니다. 15060 표준을 서비스 팩에 반영할지 결정 필요 (반영 시 health_check
   프로브 포트도 함께).

3. **HTTPS 통계의 agent 내부 트래픽** — 교정된 HTTPS 통계의 대부분(POST 28만건/일)이 agent

   엔드포인트(/api/agent/*)를 제외하거나 분리 표기할 수 있습니다 — 원하시면 적용.
